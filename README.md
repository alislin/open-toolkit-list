# 🧰 Open Toolkit · 开源工具收藏夹

个人开源工具收藏夹：**数据与展示分离的纯静态站点**，零构建、零依赖、无需后端。

数据由智能体代理维护——只需丢给它一个项目地址，抓取信息、分类、打标签、写入数据、提交 Git 全部自动完成。

## 使用方式

**本地使用**：直接双击 `index.html` 即可在浏览器打开（数据以 `data/tools.js` 脚本形式加载，不受 `file://` 的 CORS 限制）。

**发布上线**：推送到 GitHub 后，在仓库 Settings → Pages → Source 选 `main` / `(root)` 分支即可开启 GitHub Pages，随处访问。

## 功能

- 🔍 搜索：名称 / 描述 / 标签 / 备注，多关键词
- 🗂 分类侧栏 + 标签多选组合筛选（由数据动态统计生成）
- 🏷 状态标记：在用 / 试用 / 备选 / 弃用
- ⭐ 自动同步 GitHub 元数据：star 数、语言、License、最近推送、归档状态
- 📌 置顶、备注心得、卡片展开详情、暗色模式（跟随系统 + 手动切换）

## 让代理添加一个工具

在本仓库目录下对任意编码智能体（OpenCode 等）说：

> 添加收藏：https://github.com/BurntSushi/ripgrep

代理会按 `AGENTS.md` 中的规范自动抓取仓库信息、生成中文描述、归类打标、追加数据并提交。

## 目录结构

```
open-toolkit/
├── AGENTS.md        # 代理维护手册（数据规范 + 新增/刷新流程）
├── README.md
├── index.html       # 唯一页面，样式与逻辑全部内嵌
└── data/
    └── tools.js     # 收藏数据，唯一数据源
```

## 日常维护

- **新增**：把地址丢给代理即可。
- **刷新元数据**：对代理说「刷新数据」，它会批量更新 star / 归档等字段（`syncedAt` 超期条目可优先处理）。
- **手动改**：直接编辑 `data/tools.js`，字段说明见文件头注释与 `AGENTS.md`。
